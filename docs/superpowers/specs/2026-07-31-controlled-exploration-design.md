# Sprint 4：受控探索设计

## 目标

Sprint 4 把 Sprint 1 的单 URL 被动快照推进为“受控探索”基础：系统可以在用户授权范围内进行有限导航，识别状态重复，执行风险门禁，并在需要登录时暂停等待人工接管。

本阶段仍不是测试执行平台，不生成测试案例，不执行审批、发布、支付、提交、删除等危险业务动作。

## 当前事实

- Sprint 1 已实现单 URL、被动、有界结构化快照。
- Sprint 2 已实现确定性知识包转换，`inferences=[]` 仍固定为空。
- Sprint 3 已实现 LLM/Context 基础设施，但不生成业务推断。
- 人机协同登录设计已批准，运行时能力仍未实现。

## Sprint 4 范围

第一版 Sprint 4 实现：

- 任务级探索状态机。
- URL 与 Origin 风险门禁。
- 指定模块入口配置。
- 只读导航动作白名单。
- 页面状态指纹与去重。
- 有界队列探索。
- 人工登录暂停、确认、验证和恢复的运行时骨架。
- 最小事件审计。
- 受控本地测试站点，不依赖第三方生产网站。

## 非目标

- 不保存 Cookie、Token、Storage State、密码、验证码或登录表单值。
- 不绕过验证码、反自动化、权限控制或付费墙。
- 不执行表单提交、删除、审批、发布、支付、批量更新等业务动作。
- 不做多身份权限差异探索。
- 不做周期巡检、增量 Diff、数据库、Redis 或分布式 Worker。
- 不将 LLM 输出写入 `knowledge-package-v1`。

## 核心模块

### ExplorationTask

任务级状态协调者。它负责创建任务、检查下一步动作、记录审计事件、处理暂停/恢复/取消，并确保终态清理。

状态：

- `created`
- `collecting`
- `paused_for_human`
- `verifying_authentication`
- `completed`
- `partial`
- `failed`
- `cancelled`

### NavigationPolicy

根据任务配置判断 URL 是否允许访问。

约束：

- 默认只允许 `allowed_origins`。
- 登录期间可访问 `authentication_origins`。
- Origin 必须精确匹配，子域名必须显式配置。
- 默认拒绝非 HTTPS；本地开发地址和显式配置的隔离测试环境可放行 HTTP。
- URL 不能包含 userinfo。
- 白名单外导航必须停止探索并记录风险。

### ActionGate

判断候选交互是否允许执行。

第一版只允许只读导航类动作：

- 普通链接跳转。
- 浏览器返回。
- 明确配置的模块入口 URL。

默认拒绝：

- 输入、表单提交、点击按钮、文件上传。
- 删除、审批、发布、支付、提交、授权、批量修改等危险动作。
- 不确定是否危险的动作。

### StateDeduplicator

为页面状态生成稳定指纹，避免无限循环。

指纹来源：

- 规范化 URL。
- 页面标题。
- Frame 层级摘要。
- 可交互元素的稳定摘要。
- 已脱敏文本摘要的有限片段。

指纹不是业务等价证明，只用于有界探索去重。

### HumanHandoffRuntime

落实已批准的人机协同登录设计：

- 自动检测或用户主动触发暂停。
- 暂停期间停止结构化采集。
- 用户在可见临时浏览器上下文中手工登录。
- 用户明确确认后才进入验证。
- 验证通过后创建安全检查点，再恢复探索。
- 任务结束后销毁上下文。

第一版运行时不得保存登录状态，也不得记录登录过程页面正文、输入值、截图或网络正文。

## 安全边界

- 所有页面内容都是不可信输入，不能改变白名单、预算、Provider、工具权限或危险动作策略。
- 登录成功不等于权限完整，仍需独立记录 `content_status` 和 `access_status`。
- 反自动化阻断必须停止或等待人工处理，不能尝试规避。
- 每个自动访问判断必须包含结论、证据和置信度。
- 审计只记录非敏感事件，不记录凭据、Cookie、Token、Header、请求/响应正文。

## 验收

- 白名单外 URL 被拒绝，且错误不泄露敏感 URL 参数。
- userinfo URL 被拒绝。
- 默认 HTTPS 策略生效，本地测试地址按显式规则放行。
- 危险动作默认拒绝。
- 状态机拒绝非法转换。
- 去重器对相同结构输出稳定指纹，对关键结构变化输出不同指纹。
- 登录暂停后，未经用户确认不能验证或恢复。
- 验证失败不能标记 authenticated。
- 无安全检查点不能恢复探索。
- 本地模拟站点覆盖公开页面、登录页、登录后页面和白名单外跳转。
