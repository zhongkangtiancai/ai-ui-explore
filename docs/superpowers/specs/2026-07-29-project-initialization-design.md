# AI UI Explorer 工程初始化设计

## 目标

在空目录建立可运行、可测试的 FastAPI + Vue 工程骨架，并将已确认的产品约束固化为
后续开发必须遵守的项目基线。

## 设计

后端只提供版本化健康接口；前端只提供服务状态页。两者通过可配置 API 基地址连接。
数据库、Redis、Playwright、LLM 和 Agent 均留到独立 Sprint，不在初始化中创建空实现。

项目采用 Python 3.12、Node.js 24、项目内虚拟环境和 pnpm。所有依赖锁定，秘密信息只
通过环境变量注入。测试、静态检查、类型检查和生产构建共同构成验收门禁。

## 产品冻结

V1 为权限感知核心版；周期巡检与增量 Diff 属于 V1.1。测试生成和自动化执行不属于 V1。
