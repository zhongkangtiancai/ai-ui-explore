# 本地权限比较用户验收闭环设计

## 目标

把已实现的人工协同登录和多身份 UI 可见性比较能力，包装成企业测试人员可重复执行的本地验收闭环。该闭环只验证受控身份下的 UI 可见性观察、保守的不确定结果、取消、安全导出和终态结果回读；不验证业务授权、后端数据权限、真实外站登录、SSO、MFA 或访问控制绕过。

## 范围

本切片交付三项内容：

1. 一个独立启动的本地虚构角色验收站；
2. 权限比较表单中的受控人工登录与本地 HTTP 配置；
3. 中文用户验收手册和自动化验证。

终态任务与比较结果的前端历史查询不在本切片内。后端 Sprint 10 的终态持久化回读能力保持不变。

## 本地验收站

新增脚本只监听 `127.0.0.1`，不接受修改绑定地址的参数，不访问外网，也不读取环境变量中的凭据。站点提供管理员、普通用户和受限用户三个虚构角色按钮。角色选择只在当前浏览器 Context 的会话 Cookie 中保存；关闭 Context 或进程后失效。

站点行为：

| 路径 | 行为 |
| --- | --- |
| `/login.html` | 提供三个固定角色按钮，不含账号、密码、Token 或 Cookie 输入。 |
| `/login-complete?role=...` | 仅接受固定角色，设置虚构角色 Cookie 后跳转工作台。 |
| `/dashboard.html` | 所有已登录角色可见，包含 `#signed-in-marker`。管理员可发现管理页，受限用户可发现受控失败页。 |
| `/admin.html` | 仅管理员可由工作台链接发现的专属页面。 |
| `/collector-failure.html` | 仅受限用户可发现，主动中断本地连接以稳定模拟采集失败。 |

未登录访问受保护页面时跳回登录页。该站不把页面不可见描述为业务授权结论。

## 前端配置与数据流

权限比较表单增加显式的“需要人工登录”与“仅本地验收：允许 HTTP”开关，默认均关闭。开启人工登录后，每个身份必须提交独立的认证 Origin、认证 URL、登录后 URL 前缀和检查点 CSS；这些字段构成现有 `AuthenticationPlan`，不引入凭据字段。

表单只能在用户明确勾选本地验收 HTTP 时提交 `allow_local_http: true`。后端继续使用既有 `NavigationPolicy`：非 HTTPS 仅在 `localhost`、`127.0.0.1` 或 `::1` 被允许，认证 URL 必须在认证 Origin 内，登录后前缀必须在允许 Origin 内。

每个身份仍由已有比较服务串行执行：浏览器暂停供人工点击虚构角色，用户回到应用确认登录，检查点通过后开始只读探索。浏览器对象、Cookie、Token、Storage State、密码、原始 DOM/HTML 和网络正文不会经 API、前端状态、导出或持久化路径暴露。

## 验收场景

1. 管理员与普通用户：管理员专属页面表现为高可靠性 UI 可见性差异，比较完成。
2. 管理员与受限用户：受限身份的本地失败页使比较为 `partial`，差异全部为 `inconclusive`，不得显示“无权限”或业务授权结论。
3. 取消：首个身份等待人工确认时取消，后续身份不启动，当前浏览器关闭。
4. 安全导出：JSON 为 Schema 校验附件，且不含密码、Token、Cookie、Storage State、原始 HTML 或浏览器对象。

验收手册要求使用本地虚构站，不得使用生产账号或生产业务数据；也会说明服务重启后运行中的浏览器任务不可恢复，而已持久化的脱敏终态结果可由既有 Sprint 10 API 查询。

## 错误处理与安全属性

- 非本地 HTTP、认证 Origin 不匹配、认证计划不完整或无效角色均应被现有验证或本地站拒绝，不暴露运行时异常详情。
- 前端请求失败只显示既有安全错误提示，不回显提交内容。
- 本地站的失败页仅用于测试采集缺失导致的不确定性，不能推导权限或业务结论。
- 不引入外网依赖、凭据、截图持久化或登录态跨进程恢复。

## 测试策略

所有生产改动遵循测试优先：先新增并观察失败测试，再最小实现。

- 前端组件测试验证：默认不提交本地 HTTP 或认证计划；启用人工登录后提交每身份的完整认证计划；页面不渲染凭据输入。
- 本地站测试验证：仅绑定 loopback、未知角色不获得登录态、受限失败页行为固定。
- 后端/Chromium 集成测试复用本地站，验证三类身份场景、串行行为、取消、关闭与安全导出。
- 最终运行相关后端、前端质量门和本地 Chromium 验收；任何未实际运行的命令必须明确说明。

## 非目标

不实现前端历史结果列表、跨进程登录态恢复、真实外站验收、SSO/MFA、后端数据权限推断、模型调用、Agent、自动化测试代码生成或生产部署。
