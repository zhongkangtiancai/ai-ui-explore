# 安全与风险基线

## 默认拒绝的动作

删除、审批、发布、支付、提交、授权、批量修改以及不可逆外部调用默认禁止。
允许执行时必须匹配显式白名单；业务影响较大的动作还需要人工确认。

## 敏感数据

账号、密码、Cookie、Token、API Key、个人信息、客户数据、网络请求体和截图不得进入
Git。持久化前需要字段级脱敏，并设置访问控制和保留期限。

## 已知能力盲区

- Canvas、纯图像控件和低可访问性页面在没有 VL 模型时可能无法可靠理解。
- CAPTCHA、MFA 和扫码通常需要人工介入。
- Playwright 能操作多数跨域 iframe，但 sandbox、第三方安全策略和动态加载可能限制探索。
- 数据权限不能只凭列表行数或可见数据推断。

## 审计

未来每个浏览器动作都必须记录身份、时间、页面状态、目标、风险判断、执行结果和证据，
且不得在审计日志中保存明文秘密。
