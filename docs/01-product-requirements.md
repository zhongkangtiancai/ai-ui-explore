# 产品需求基线

## 目标

自动探索企业 Web 应用，将真实系统状态转化为人和 AI 都能消费、可追溯且可更新的
Application Knowledge Model，从而弥补需求文档和 UI 原型不完整、不准确或过时的问题。

## V1 输入

- 应用入口和探索范围
- 登录方式及人工协助策略
- 一个或多个受控测试身份
- 危险动作白名单
- 最大探索深度、页面数量和时间预算

## V1 输出

- 应用与模块地图
- 页面、元素、动作和流程知识
- 多身份下的菜单、页面和动作差异
- 每项 AI 推断对应的证据和置信度
- 面向 AI 消费的 JSON 知识包

## 非目标

- 自动生成测试案例
- 自动生成 UI 自动化代码
- 自动执行回归测试
- 无人工边界的自主高风险操作
- 在缺少证据时断言数据权限规则

## 成功标准

在受控测试环境中，对指定业务模块完成有边界的探索，并生成可追溯、可复查、
可导出的知识结果；低置信度和证据不足的内容必须清楚标识。
