# 部署与离线交付基线

## 环境策略

采用同一套代码、多环境配置：

- development：外网开发机，可使用公网模型验证
- enterprise-test：内网测试环境，使用私有 OpenAI-compatible 网关
- production：内网生产环境，增加访问控制、备份和审计

## 最终离线交付物

- 应用源码和锁定依赖
- Python wheel 包、Node 包及 Playwright 浏览器
- 后端、前端、数据库、Redis 和 Worker 容器镜像
- 数据库迁移、安装、升级、备份和回滚脚本
- 配置、部署、运维和故障处理手册
