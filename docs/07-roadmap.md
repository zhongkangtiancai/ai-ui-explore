# 研发路线

## Sprint 0：工程初始化

前后端可运行骨架、项目文档、质量检查、锁文件和健康检查闭环。

## Sprint 1：结构化页面快照

使用 Playwright 采集页面、Frame、DOM 摘要、Accessibility 和可交互元素，
输出有边界的 JSON 快照；不调用 LLM。

## Sprint 2：知识模型

实现事实、证据、推断和置信度的数据结构、持久化与 JSON 导出。

## Sprint 3：LLM 与上下文

实现 Provider 抽象、Mock、Token 预算、裁剪、缓存和调用审计。

## Sprint 4：受控探索

实现导航、状态去重、风险门禁、指定模块探索和人工辅助登录。

## Sprint 5：权限感知

实现多身份探索、菜单/页面/动作差异和权限证据视图。

## V1.1

实现周期巡检、增量探索、版本时间线和变化报告。
