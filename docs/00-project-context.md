# AI UI Explorer 项目上下文

## 已确认事实

- 目标用户是企业内部测试团队。
- 目标系统以中文、中大型 Vue/React SPA 为主，包含 iframe 和复杂登录。
- 登录方式可能包括用户名密码、SSO 和扫码，允许人工辅助并复用登录状态。
- 系统需要支持指定模块探索和全应用探索。
- 核心输出面向人和 AI，包括页面、元素、动作、流程、权限及证据。
- 外网开发可使用 GPT 或 DeepSeek；内网使用 DeepSeek/Qwen 的
  OpenAI-compatible API。
- 最终交付需要支持企业内网离线部署。

## 产品边界

V1 是“权限感知核心版”：支持单系统、指定模块优先、多身份差异、页面/元素/
动作知识、证据、置信度和 JSON 导出。

V1.1 再实现周期巡检和增量 Diff。

测试案例生成、自动化代码生成和回归执行不是 V1 范围，它们是知识模型的后续消费者。

## Sprint 7 已验证能力

单次探索任务可在当前后端进程内浏览已采集、已脱敏的页面、Frame、元素、边界和定位器候选明细。任务内 `page-N` 是详情读取的安全标识，脱敏 URL 仅用于展示。FastAPI 提供页面列表、单页详情和 Schema 校验的 JSON 下载，Vue 提供只读浏览和下载入口。

页面证据不保存原始 Snapshot、HTML、网络正文、Cookie、Token、输入值或浏览器对象；服务重启后任务和证据均不可恢复。`partial` 仅表示采集不完整，不表示权限拒绝、页面不存在或业务结论；定位器候选是观测信息，不承诺跨版本稳定，也不自动生成或执行自动化代码。真实 Chromium 验收仅覆盖本地虚构登录站点。

## Sprint 8 统一探索知识包

Sprint 8 在当前进程内把已经脱敏的终态任务证据与权限对比结果按需构建为独立的 `exploration-knowledge-package-v2`。该 JSON 包包含直接观察到的页面、元素、定位器候选、可见性差异、证据引用、可靠性与知识缺口；`inferences` 固定为空。来源目录与下载 API 只接受终态投影，导出不读取原始 Snapshot、DOM、HTML、网络正文、浏览器对象、Cookie、Token、输入值或登录态，也不写入文件或数据库。

该包最多接受 5 个来源、500 页、20,000 个元素、20,000 条差异、50,000 条证据和 10 MiB UTF-8 JSON；任何预算超限都会拒绝导出而不会静默截断。`partial`、认证未验证、采集失败或不可匹配会保留为 Observation、KnowledgeGap 或 inconclusive 差异，绝不升级为业务权限、后端数据范围或角色结论。服务重启后来源与导出包都不可恢复。

## 当前实现

当前已建立前后端可运行工程骨架，实现 Sprint 1 的 Playwright 单 URL 有界结构化
快照采集，并实现 Sprint 2 的确定性 Application Knowledge Model 转换闭环：从
Application Manifest 和已校验的 Snapshot 1.0/1.1 生成独立、脱敏、Schema 校验且
可追溯的 `knowledge-package.json`。Snapshot 1.1 包含分层、排序、当前 Frame 内校验的
定位器候选；Snapshot 1.0 继续兼容读取。

Sprint 3 已实现 LLM 与上下文基础设施：Provider 抽象、确定性 Mock、OpenAI-compatible
非流式适配器、Context Manager、保守 Token 估算、按完整知识记录裁剪、Evidence 引用
闭包、有界进程内缓存、脱敏调用审计字段和薄 Runtime。默认质量门不访问真实模型。

Sprint 4 已完成第四切片。在前三个切片中实现了受控探索的纯模型基础，包括 URL/Origin
风险门禁、只读动作门禁、任务状态机、最小审计事件、页面状态指纹、状态去重、指定模块入口配置和
有界探索队列模型、可注入 Snapshot Collector Port 的有界 Runner 编排，以及复用 Sprint 1
`SnapshotCollector` 的适配器。Snapshot 1.1 已保存经过 URL 脱敏的 anchor `href`
导航元数据，并可从页面快照确定性提取去重后的只读链接导航候选；Runner 默认接入该
提取器，并在遇到重复页面状态时停止继续展开候选。已通过本地 HTTP fixture 与真实 Chromium
完成入口页到同源链接页的端到端验收；验收同时覆盖 `max_pages` 预算边界。

第四切片实现了后端人机协同登录运行时：任务使用进程内存态的可见 Playwright Browser Context，
由人工显式确认后，按配置的登录后 URL 前缀和 CSS 检查点验证认证结果；验证成功后，Runner 可通过
具体会话 Collector 的模块私有、精确类型及 source/session/task 对象身份校验，恢复同一 Context 的
受控只读探索；Collector Port 不公开可由包装器伪造的任务绑定能力。
Runner 绑定同一任务时，会在 completed/partial 结果落定后同步驱动对应终态；候选提取、队列等未处理
异常会在重新抛出前把任务置为 failed。终态回调逐个隔离清理异常并继续关闭浏览器，且不会覆盖 Runner
原始异常；该保证只覆盖当前进程仍能执行清理代码的情况。该能力只通过本地 HTTP 模拟登录站点与真实 Chromium 验收，不持久化 Cookie、Token
或浏览器存储状态，也未对真实外部登录流程做出可用性声明。

Sprint 5 已完成受控探索的最小任务管理闭环：单进程、加锁的内存任务注册表保存私有运行时
句柄与脱敏公共视图；后台线程执行受控探索；FastAPI 提供创建、查询、审计、人工登录确认、
取消和结果摘要接口；Vue 页面提供对应的最小创建与观察交互。登录任务由可见 Browser Context
在其所属后台线程中启动、确认、验证、采集和关闭，前端/API 不暴露浏览器对象、凭据、Cookie、
Token 或浏览器存储状态；结果摘要只保存页面、元素和链接的标量计数。已使用本地 HTTP 模拟登录
站点、真实 Chromium 和 API 完成端到端验收：
创建任务、等待人工登录、测试私有辅助模拟本地登录、确认、完成、读取脱敏摘要与终态关闭。
进程重启会丢失任务、结果和登录态；进程崩溃或被强制终止时不保证 finally 清理能够执行。

这些能力不是完整应用探索。跨任务登录态复用、加密登录态存储、SSO/扫码/MFA 专用适配、
真实外部站点登录、访问控制绕过、截图、网络正文、业务动作、真实模型验收、Agent、推断生成、
数据库、Redis、独立 Worker、跨进程恢复、后端数据权限验证、测试案例/自动化代码生成和巡检仍未
实现；上述 V1/V1.1 产品能力中未在本段明确列为已实现的部分均为规划。

Sprint 6 已实现进程内的多身份 UI 可见性比较：2–5 个非敏感身份别名按顺序使用独立、可见的
Browser Context 完成人工登录和受控只读探索；成功快照仅投影为脱敏、受限的页面与元素证据，
随后以保守的稳定键比较页面、元素与链接目标。任何身份认证未验证、采集失败或被截断时，整体
结果标记为 partial，全部差异都明确为“无法确认”，不会推断业务权限。FastAPI 提供比较详情、
页面证据、差异和内存 JSON 下载，Vue 提供显式比较模式且默认隐藏低可靠性差异。该能力仅通过
本地虚构多角色 HTTP 站点和真实 Chromium 验收；它证明 UI 可见性证据链，不证明后端数据范围
或业务授权。
